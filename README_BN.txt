TradeLens AI — PWA starter (Quotex Signal Lab)

এটি একটি ডেমো। এটি লাইভ Quotex/OTC ডেটা পড়ে না, কোনো অ্যাকাউন্টে লগইন করে না, এবং অটো-ট্রেড করে না।

APK তৈরির সহজ পথ:
1. ZIP ফাইলটি extract/unzip করুন।
2. index.html, manifest.webmanifest এবং sw.js একই ফোল্ডারে রাখুন।
3. HTTPS-সমর্থিত hosting-এ এই 3টি ফাইল আপলোড করুন (যেমন GitHub Pages)।
4. আপনার প্রকাশিত HTTPS ওয়েবসাইটের URL PWABuilder.com-এ দিন।
5. Android package/build অপশন নির্বাচন করে package তৈরি করুন। APK/ZIP ফলাফল ডাউনলোড করুন।
6. APK নিজের ফোনে ইনস্টল করার আগে ফাইলের উৎস যাচাই করুন। Android-এ অনুমতি চাইলে শুধু বিশ্বস্ত ফাইলের জন্যই অনুমতি দিন।

নোট:
- PWABuilder-এর Android packaging সাধারণত সঠিকভাবে hosted PWA/HTTPS URL চায়।
- APK বানানো মানেই Google Play-তে প্রকাশের অনুমতি নয়।
- নিজের signing key/পাসওয়ার্ড কাউকে দেবেন না।
- লাইভ ডেটার জন্য অনুমোদিত data provider/API প্রয়োজন; Quotex login/password কোনো তৃতীয় পক্ষের সাইটে দেবেন না।
